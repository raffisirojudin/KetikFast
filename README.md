# ⚡ KetikFast Ultimate 2.0

Website belajar dan latihan mengetik 10 jari interaktif berbasis **Biomechanical Telemetry**, **Smart Indonesian Bigram AI**, **Ghost Pacemaker**, dan **RPG Boss Battle Arena**.

## ✨ Fitur Unggulan
- **5 Mode Permainan**: Mode Waktu (15s–120s), Jumlah Kata (10–100 kata), Kutipan Utuh, **Akademi 10 Jari (Level 1–6)**, dan **RPG Boss Battle**.
- **Biomechanical 10-Finger Zones & Dual-Hand SVG**: Panduan visual posisi 10 jari secara *real-time* beserta keyboard mekanikal 3D/2D dengan tonjolan taktil `F` & `J`.
- **Smart Indonesian Bigram & Weak-Keys AI**: Meracik latihan kata asli Bahasa Indonesia berdasarkan huruf rawan salah dan transisi 2-huruf (*bigram*) paling lambat milikmu.
- **Live Keyboard Heatmap & SVG Telemetry Chart**: Peta panas akurasi/kecepatan per tombol dan grafik kurva WPM per detik setelah latihan.
- **WebAudio Synthesizer & Rhythm Metronome**: Efek suara mekanikal (*Thocky, Clicky, Creamy, Piano, Synth*) tanpa file audio eksternal + metronom ritme ketikan.

## 📂 Struktur File
- `index.html` / `ketik.html` — Halaman utama aplikasi (siap untuk GitHub Pages)
- `style.css` — Tema warna, layout keyboard 3D/2D, zona jari, dan animasi
- `data.js` — Bank kalimat, kamus kata Bahasa Indonesia, kurikulum Akademi, dan profil Boss RPG
- `app.js` — Logika utama aplikasi, telemetri biometrik, dan mesin audio

## 🚀 Cara Menjalankan
- **Secara Lokal**: Buka `index.html` atau `ketik.html` langsung di browser.
- **GitHub Pages**: Aktifkan melalui menu **Settings > Pages > Branch: `main` (root)** pada repositori GitHub.
